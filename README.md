# CreditTitan AI

CreditTitan AI is a single-page web app that turns a user's personal and business
credit profile into a practical strategy output in minutes.

## What it does

- Collects personal credit inputs (score, utilization, late payments, collections, inquiries, account age, income)
- Collects business credit inputs (business age, revenue, tradelines, entity setup)
- Generates:
  - Credit score projection windows
  - Prioritized credit repair actions
  - Intelligent personal and business credit option suggestions
  - Fast-track business credit roadmap
  - "Millionaire decision" leverage rules for risk-aware credit usage

## Run locally

This project is static HTML/CSS/JS.

1. Open `index.html` in a browser, or
2. Serve the folder with any static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Important note

This tool is educational and planning-focused. It does not guarantee specific
credit score outcomes.
